# World News — 23 November 2026

A Chinese classical-style daily brief summarising the top world news of 23 November 2026.
The image `news-20261123.jpg` (1024×683) is the entry; `main.py` outputs it
deterministically. The news text on the image is in English.

## The 7 stories

1. **Trump warns Iran** — strikes may resume in the New Year; Iran hits a U.S. base in Bahrain.
2. **COP31 collapses** — climate talks end with no deal; the longest UN climate summit ever.
3. **Russia strikes Kyiv** — deadly attacks; NATO holds emergency talks as Russian missiles enter Poland.
4. **Democrats' big win** — largest U.S. House majority since 1992 (at least 258 seats).
5. **Gaza crisis** — Israeli strike kills 3; Oxfam reports 99% of Gaza contaminated.
6. **Cartel kingpin caught** — Mexico captures Sinaloa leader "Chapo Isidro".
7. **Seoul scandal** — South Korea's education minister quits over AI cheating days before the Suneung exam.

## How to run

```sh
python3 main.py > news.jpg
```

The program only reads the bundled image and writes its bytes to stdout.
No network access, no randomness — running it twice produces identical bytes.
